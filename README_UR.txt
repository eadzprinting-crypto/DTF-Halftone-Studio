DTF Halftone Studio — Windows EXE project

Features:
- Open PNG, JPG/JPEG, TIFF, BMP, WEBP
- Halftone preview and controls for dot size, screen angle, contrast and threshold
- Black, white, color and grayscale modes
- Optional transparent background and inverted tones
- Full-resolution PNG export (original image dimensions)

Important:
This package contains the app source and a Windows build script. A Windows EXE must be compiled on Windows (or on a Windows build runner). This folder itself is not the compiled EXE.

Build on a Windows PC:
1. Install Python 3 from python.org and enable "Add Python to PATH".
2. Double-click build_windows.bat.
3. The EXE will be created at dist\DTF_Halftone_Studio.exe.
4. After building, the EXE can be copied to another compatible Windows PC; Python is not needed on that other PC.

No Photoshop plugin is required.
